# Formosa Works

Portfolio page for seven health-technology concepts submitted to **Go Healthy with Taiwan 2026**.
Static Next.js site — no backend, no database, no forms.

## Running it

```bash
npm run dev
```

Then open http://localhost:3000.

```bash
npm run build
```

Builds and prerenders every page, including one static page per entry.

```bash
npm run check:prose
```

Verifies the paragraph splitter (below) still reproduces every entry's prose
word for word, and flags any long field still rendering as a single wall of text.
Worth running after editing `data/entries.ts`.

## Editing the content

**You should never need to touch a component to change what the site says.**

| What you want to change | File |
| --- | --- |
| Studio name, tagline, about text, team contacts, competition details | `data/site.ts` |
| The seven entries — every field, in display order | `data/entries.ts` |
| Colours, type, spacing | `app/globals.css` |
| Browser tab / home-screen icon | `app/icon.svg`, `app/apple-icon.tsx` |

### Adding or editing an entry

Entries render in the order they appear in the `entries` array in `data/entries.ts`.
Add an object to that array and a card plus a `/entries/<slug>` brief page appear
automatically. The Taiwan Partners section rebuilds itself by deduping the
`products` and `partners` across all entries, so nothing there needs updating by hand.

Everything inside `brief` is optional. An entry with no `pest` or `businessModel`
simply renders fewer sections on its brief page — no gaps, no placeholders.

Required per entry: `slug`, `name`, `proposalTitle`, `tagline`, `accent`,
`industries`, `issues`, `problem`, `coreIdea`, `products`.

`accent` is the card's field colour. Keep new ones desaturated — the palette is
paper and ink with a single red accent, and a saturated card breaks it.

### Long paragraphs

Proposal fields like `businessModel` arrive as single 200–250 word blocks.
`lib/text.ts` breaks them into balanced paragraphs at sentence boundaries at
render time — it only ever inserts breaks, never edits or drops a word, so what
appears on the page still matches the proposal exactly. Write the content as one
block; the site handles the rhythm. `npm run check:prose` guards the invariant.

## Design notes

- **Palette** — cream paper `#fbf6ea` and ink `#16142a` as the base, with violet
  `#4b3fd4`, lime `#d6f24e`, pink `#f5399b`, sky `#9ad5f5` and lilac `#ded5fb` as
  the pops. Each entry also carries its own saturated field colour, which drives
  its card tint, its offset shadow, its detail labels and its brief-page header.
- **Colour blocking** — the page alternates full-bleed backgrounds (cream hero →
  violet marquee and about → cream entries → lilac partners → ink footer),
  separated by SVG wave dividers rather than straight rules.
- **Hard-edged UI** — 2px ink outlines, generous corner radii and solid offset
  shadows on cards, pills and badges. No blurs, no gradients, no drop shadows.
- **Type** — Instrument Serif for display, Archivo for body, JetBrains Mono for
  labels and tags. Self-hosted through `next/font`; no external requests at runtime.
- **Structure** — single scrolling page (hero, marquee, about, entries, partners,
  footer) with a statically generated long-form brief at `/entries/<slug>`.
  Cards expand in place for the summary; the brief page carries the full proposal.

## Deploying

The site is fully static. Push to a Git host and import into Vercel or Netlify —
no environment variables, no build configuration. Vercel detects Next.js and uses
`npm run build` on its own; nothing needs setting in the project settings.

The icon is a lime "F" on violet with a pink dot. `app/icon.svg` becomes the
browser tab favicon; `app/apple-icon.tsx` renders a 180×180 PNG at build time for
iOS home screens. Both are generated by Next's file conventions — there is no
`favicon.ico` to maintain.

To export plain files instead, add `output: 'export'` to `next.config.mjs` and run
`npm run build`; the result lands in `out/` and can be dropped onto any static host.

## Note on scope

This is a portfolio page, not the competition submission. The submission is made
through the organiser's own form.
